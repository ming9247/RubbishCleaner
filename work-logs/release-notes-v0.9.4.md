## RubbishCleaner v0.9.4

针对「需手动处理」的残留项（计划任务 / Windows 服务 / 启动文件夹快捷方式）：
以前只给一条命令和一段路径文字，新手不知道去哪儿点。现在每条下面多了一排按钮和分步提示。

### 现在怎么用

| 类型 | 按钮 | 点了之后 |
|---|---|---|
| 残留计划任务 | 打开「任务计划程序」并复制任务名 | 打开 `taskschd.msc`，任务名（带前导 `\` 的完整名）已在剪贴板；提示：左侧「任务计划程序库」→ 按名称找 → 右键删除 |
| 残留 Windows 服务 | 打开「服务」并复制服务名 | 打开 `services.msc`，服务名已在剪贴板；提示：先核对「可执行文件的路径」→ 停止 → 再用管理员命令删 |
| 启动文件夹快捷方式 | 在文件夹中选中该快捷方式 | 资源管理器直接**选中那个 `.lnk`**，按 Delete 即可（不需要管理员） |

另外每条都补了「复制名称」「复制命令」按钮（原来只能靠鼠标在只读框里选中复制）。

### 为什么还是让用户自己按那一下删除

删服务可能牵连依赖它的其它服务；计划任务也可能正被某个软件正常使用（我们只判定"指向的文件不存在"）。
工具负责把用户送到正确的位置、把名字和命令备好——决定权留给用户，这和「绝不静默删除」的一贯原则一致。

### 一个必须说清的限制

Windows **没有**「打开某界面并选中指定项」的命令行接口：

- `services.msc` / `taskschd.msc` 都没有定位参数；
- `regedit` 可以用 `LastKey` 指定位置，但只在 regedit 未运行时生效、且退出时会覆盖它；
- 只有资源管理器的 `explorer /select,` 能真正选中。

所以服务与计划任务做到的是「打开正确的界面 + 名字进剪贴板 + 三步提示」，没有假装"已经选中"。
