## RubbishCleaner v0.9.1

本次只有一处新增：**设置页底部多了「关于软件」卡片**，里面放了一个赞助作者的入口。

### 设置页「关于软件」

- 显示程序名与版本号（读程序集，`csproj` 的 `<Version>` 是唯一真源）与项目主页
- **「在爱发电赞助作者」按钮**：点击后用系统默认浏览器打开 <https://afdian.com/a/coco5280>
- 卡片里也直接写出了赞助页地址，浏览器打不开时可以手动复制

### 关于赞助的几个明确约定

| 约定 | 说明 |
|---|---|
| 不弹窗 | 打开成功/失败都只在卡片里一行文字反馈；启动时不打扰、不自动跳转 |
| 不在应用内支付 | 不接支付 SDK、不读取账号、不收集点击，点击等价于你自己打开官网链接 |
| 不影响功能 | 赞助完全自愿，工具的全部功能与赞助与否无关，没有会员/解锁设计 |
| 不依赖联网开关 | 赞助是浏览器外链，和「启用联网（特征库在线更新）」无关；联网默认仍是关闭的 |

### 其它

- 版本 `0.9.0 → 0.9.1`；特征库不变（`version 3`，白名单 19 / 黑名单 26）
- 测试：**676 passed / 0 failed**（Core 486 + App 190，新增 6 项针对「关于软件」）
