## 4. 权限说明（重要）

当前 DSH 会话以**标准用户**运行（`IsInRole(Administrator) == false`）。这对本项目意味着：

| 场景 | 标准用户 | 管理员 |
|------|---------|--------|
| 构建 / 单元测试 | ✅ 完全可用 | ✅ |
| HKCU Run 读取 | ✅ | ✅ |
| HKLM Run 读取 | ✅（读权限通常开放） | ✅ |
| 启动文件夹扫描 | ✅ | ✅ |
| Windows 服务枚举 | ⚠️ 大部分可读，个别键拒绝访问 → 降级 | ✅ |
| 计划任务扫描 | ❌ 目录拒绝访问 → 降级并提示 | ✅ |
| 运行 WPF 主程序 | 会弹 UAC（清单要求管理员） | ✅ |

**实测证据**：

```
$ (Get-ChildItem C:\Windows\System32\Tasks)
Access to the path 'C:\Windows\System32\Tasks' is denied.
```

扫描结果中该数据源被正确标记为降级：

```
降级的数据源：
  - 计划任务：无法读取计划任务目录，请以管理员身份运行以获得完整结果。
```

> 这正是设计中的**降级路径**（技术文档 §8.1）。开发期不需要提权即可完成绝大部分工作；
> 只有验证"计划任务检测"和"主程序 UAC 启动"时，才需要手动以管理员身份运行一次。

### 5.1 运行时依赖

**零第三方依赖**。三个产品项目（Common / Core / App）只使用 BCL 与 Win32 API。

### 5.2 开发/测试依赖

| 包 | 版本 | 用途 | 是否进入发布产物 |

> 刻意的取舍：不引入 `TaskScheduler`（计划任务 COM）、`System.Management`（WMI）、
> 日志库、MVVM 框架，以守住"绿色单文件、免运行时、体积小"的产品目标。详见技术文档 ADR-002 / ADR-005。

### 5.3 使用的 Windows API

| API | 所在 DLL | 用途 |
|-----|---------|------|
| `EnumWindows` / `IsWindowVisible` / `GetWindowLongPtr` / `GetWindow` / `GetWindowThreadProcessId` / `GetWindowTextLength` | user32 | 窗口可见性与任务栏判定 |
| `OpenProcess` / `QueryFullProcessImageNameW` / `CloseHandle` | kernel32 | 进程路径解析 |
| `MoveFileExW` | kernel32 | 重启后删除（v0.2 预留） |
| `CreateFileW` | kernel32 | 打开文件做目录签名哈希 |
| `WinVerifyTrust` / `CryptCATAdmin*` | wintrust | Authenticode + **目录签名**校验 |
| `IShellLinkW` / `IPersistFile`（COM） | shell32 | .lnk 快捷方式解析 |
| `RegistryKey`（BCL 封装） | — | 注册表读取 |

## 6. 环境复现步骤

```powershell
# 1. 检查 .NET SDK（需 8.0 或更高）
dotnet --list-sdks

# 2. 检查 .NET 8 Desktop 运行时（开发期运行 WPF 需要）
dotnet --list-runtimes | Select-String "WindowsDesktop"

# 3. 检查 Git
git --version

# 4. 检查 NuGet 连通性（仅测试包需要）
(Invoke-WebRequest https://api.nuget.org/v3/index.json -UseBasicParsing).StatusCode

# 5. 一键构建 + 测试
.\scripts\build.ps1
.\scripts\test.ps1

# 6. 无界面冒烟扫描（不需要管理员）
dotnet run --project tools/RubbishCleaner.Smoke
```

若缺少 .NET 8 SDK：

```powershell
winget install Microsoft.DotNet.SDK.8
```

## 7. 已知环境限制

| 限制 | 影响 | 应对 |
|------|------|------|
| 会话为普通用户 | 计划任务扫描降级；无法自动验证 UAC 启动 | 需要时手动以管理员身份运行一次 |
